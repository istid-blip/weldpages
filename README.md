# Welding Apps - Marketing Site

This repository contains the source code for the promotional website and landing pages for my welding applications. 

## 🌐 Live Website
You can view the live website here: https://istid-blip.github.io/weldpages/

## 📱 About the Apps
This site serves as the central hub for my Kotlin Multiplatform welding tools. It provides users with:
* Feature overviews and application screenshots.
* Direct links to download the apps from the respective app stores.
* Contact information and user support resources.

## 🛠️ Development & Maintenance
This is a static website hosted directly via GitHub Pages. 
* To update the site content, modify the HTML and CSS files in this repository.
* Changes pushed to the main branch are automatically deployed by GitHub.
